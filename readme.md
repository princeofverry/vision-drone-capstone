# How to run globally

in our raspi, we just run with global package, we have already to install it.

```
git clone https://github.com/princeofverry/vision-drone-capstone.git
```

next

```
cd vision-drone-capstone
```

if you guys already use rpi-cam 2 just run below the code for realtime detection

```
python3 trial.py
```

# Install with environment python

make the environment

```
python -m venv env
```

activate the environment with type "activate"

```
source env/bin/activate
```

if you already have environment just run:

```
pip install -r requirements.txt
```
